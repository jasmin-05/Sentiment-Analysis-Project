# Twitter Sentiment Analysis using Machine Learning

## Project Overview

This project performs sentiment analysis on Twitter data using Natural Language Processing (NLP) and Machine Learning techniques.
Model used: Logistic Regression 
Accuracy Achieved: 92.6%

## Dataset

* 162,969 tweets
* Sentiment Classes:

  * Positive (1)
  * Neutral (0)
  * Negative (-1)

## Technologies Used

* Python
* Pandas
* Scikit-Learn
* Matplotlib
* TF-IDF Vectorization
* Logistic Regression

## Workflow

1. Data Loading
2. Data Cleaning
3. Feature Extraction using TF-IDF
4. Train-Test Split
5. Logistic Regression Model Training
6. Model Evaluation
7. Sentiment Prediction

## Results

* Accuracy: 92.67%
* Successfully classified tweets into Positive, Neutral and Negative sentiments.
